## Read this first

**Two separate trees.** `~/config` and `~/.config` are *not* symlinks; they were byte-identical at
the start of the session. All edits were made in `~/config/**`, then copied into `~/.config/**` so
the running shell loads them. They are in sync now — if you edit one, mirror it:

```bash
cp config/quickshell/<path> .config/quickshell/<path>
```

**Repo locations.** `~/config/quickshell` is a git repo. `~/config/hypr` is **not** — Hyprland
edits there are untracked and only visible via this document.

**Nothing is committed**, so `git diff` in `~/config/quickshell` is the authoritative diff
(17 files, +485/−165). `Modules/Bar/Styles/Island/IslandCenterPill.qml` was already modified by
the user before this session and was only mirrored, not authored here.

## Pass 2 — Convex style + Settings app

### Convex: defects found

The style had one real geometry bug and no configuration at all.

- **Bar floated 8 px below the screen edge.** `ConvexShape.topBezel` was `Constants.sizeXs` (8) and
  is applied to the notches *and* to every bridge segment between them, so the bar's whole top edge
  sat at y=8 with wallpaper above it — except two 8 px slivers at the far left/right that still
  reached y=0. That asymmetry is what marks it a bug rather than a bezel design. Default is now 0.
- **Duplicated geometry.** `ConvexBar` built the path from its own flare constants while
  `ConvexCenter` computed notch content width from a second hardcoded copy (`sizeLg + 2`). Tuning
  one would misalign content from its notch. Both now read `convexNotchFlare`.
- **Nothing configurable, and inconsistent with Island.** Height (40), radius, flare, opacity,
  border, shadow and screen frame were all literals; `BarStyleConfig.barHeight()` hardcoded 40 for
  convex *and* 32 for island. Convex ignored the Island surface settings, so switching styles
  silently changed opacity/border/shadow behaviour.

It was a hand-written file with a gold accent (`c9a554`) that no code referenced. Added

### Keyboard layouts actually apply

The list was only saved to prefs; Hyprland's `kb_layout` comes from `userprefs.lua`, which read
exclusively from `userprefs.local.lua`.

- `SettingsService.applyKeyboardLayouts()` runs `hyprctl eval "hl.config({input = {kb_layout = '…'}})"`
  for the live session and persists the joined list through `update_veyra_prefs.py`.
- `update_veyra_prefs.py` accepts a validated `keyboard_layout` key (`us,ara` style; rejects anything else).
- `hypr/userprefs.lua` now merges `veyra_prefs` as a fallback, so the generated value survives a reload
  while `userprefs.local.lua` still wins.
- The prefs list was out of sync with the compositor (`["us"]` vs live `us,ara`); it is now `["us","ara"]`.

### Per-group reset

`AppGroup` gained `showReset` + `resetAll()`; `SettingToggle`, `SettingSegmented`, `SettingSpinBox` and
`ThemedSelect` gained `defaultValue`/`defaultIndex` + `resetToDefault()`. Reset re-emits the control's
normal signal (`toggled`/`activated`/`moved`) instead of writing the bound property, so page bindings
survive. Wired on **Bar Widgets** and the three Convex groups; other pages can opt in later.

Toggles in those groups were switched from `onCheckedChanged` to `onToggled`, because a reset only
emits `toggled` and `onCheckedChanged` never fires for it.

### Convex net-speed pill

`NetSpeedService.active` was `SettingsService.barIslandMode && …`, so in Convex mode the sampler never

content-sized, so it shows `6.1 MB/s` instead of `6.1 M…`.

## Traps that cost time

1. **`settings_prefs.json` is parsed one line at a time** by a `SplitParser`. A pretty-printed file
   produces ~178 `JSON.parse` errors and the defaults silently win. Write it with
   `json.dumps(data) + "\n"` and no indentation.
2. **A wrong `HYPRLAND_INSTANCE_SIGNATURE` beats auto-detection** — exporting a stale/typo'd value
   gives `Unable to find hyprland socket` (workspace widgets empty), and *unsetting* it gives
   `$HYPRLAND_INSTANCE_SIGNATURE is unset`. Always read it from `/run/user/1000/hypr/`.
3. **The Convex bar disappears over a fullscreen window** by design (`fsTransitionProg`). Screenshot
   on an empty workspace, or you'll "discover" a bug that isn't there.
4. **A bright 1 px blue line around the screen is the tiled window's Hyprland border**, not a shell
   seam. Same for the dark band behind it — check `hyprctl activewindow` before debugging the shell.
5. `hyprctl dispatch` takes Lua: `hyprctl dispatch 'hl.dsp.focus({workspace=9})'`. The plain
   `hyprctl dispatch workspace 9` form errors in 0.57.

## Pass 5 — startup safety, versioned prefs, search that lands on the control

- **The shell now fails loudly.** `Scripts/system/start_shell.sh` starts Quickshell, waits for a
  `quickshell` layer to appear in `hyprctl layers`, and on failure prints the matching stderr
  lines, sends a critical `notify-send` (wrapped in `timeout 5`) plus a `hyprctl notify` overlay,
  and exits 1. `hypr/modules/autostart.lua` launches it instead of bare `qs`. Tested against a
  deliberately broken config: exit 1 with the real `Expected token ':'` diagnosis, not a silent
  empty screen.
- **Static check for the exact bug that killed the shell.** `scripts/check.sh` scans
  `pragma Singleton` files for two `on<Property>Changed` handlers at root indentation whose
  property is declared in the same file. Verified by re-injecting the duplicate into
  `SettingsService.qml` (check fails) and by staying green afterwards. Non-singleton files are
  skipped on purpose: `ConvexBottomHost` legitimately handles `onIsOpenChanged` on both the root
  and a nested `QtObject`.
- **Prefs are versioned and never silently reset.** Every save writes `schemaVersion: 1`. A file
  that fails to parse, or one from a newer schema, puts the session into a read-only state. The
  guard lives in `saveTimer.onTriggered`, not only in `saveSettings()`: a save requested before
  loading finished fires the timer afterwards and bypassed the function-level guard, which is how
  the first test still overwrote the file. A corrupt file is moved to `.bak-<ts>` and a critical
  notification names the backup; defaults are used for that session only.
  Tested: pretty-printed file → md5 unchanged, `.bak` created, warning logged; `schemaVersion: 2`
  → md5 unchanged, "newer than v1; keeping it untouched".
- **Search results scroll to the row.** `search_settings.py` returns the enclosing group, so
  repeated labels (`Height` appears four times on the Shell page) resolve to the right control.
  `AppContainer` expands collapsed ancestors, scrolls the row to a third of the viewport and
  flashes an accent ring for about two seconds; the request travels through
  `AppState.pendingSettingLabel`, so it survives the page being rebuilt on a tab change.
  The ring is a sibling of the Flickable — as a child it inherited content coordinates and drew
  one scroll offset above the row.
- Verified visually: `/tmp/ring2.png` (row highlighted in a group that was collapsed) and
  `/tmp/tabjump.png` (jump from Appearance to `Shell · Island Spacing & Shape · Corner Radius`).
